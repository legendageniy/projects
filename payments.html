Справочник API

Платежи

Объект payment описывает одну попытку оплаты: сумму, статус, способ оплаты и ссылку для подтверждения.

Объект платежа

{
  "id": "pay_2Hq8sK1mXz",
  "object": "payment",
  "amount": 50000,
  "currency": "RUB",
  "status": "succeeded",
  "description": "Заказ №1042",
  "confirmation_url": null,
  "metadata": { "order_id": "1042" },
  "created_at": "2026-10-20T09:41:12Z"
}

Статусы

  1. pendingждёт подтверждения покупателем
  2. succeededденьги списаны
  3. canceledотменён или истёк срок

Создать платёж

POST/v1/payments

ПараметрТипОписание
amount обязательныйintegerСумма в копейках, от 100.
currency обязательныйstringКод валюты ISO 4217, например RUB.
descriptionstringДо 128 символов, видна покупателю.
return_urlstringКуда вернуть покупателя после оплаты.
metadataobjectДо 20 пар ключ–значение для ваших нужд.
curl https://api.kvant.example/v1/payments \
  -H "Authorization: Bearer $KVANT_SECRET_KEY" \
  -d amount=50000 -d currency=RUB \
  -d return_url="https://shop.example/thanks"
const payment = await kvant.payments.create({
  amount: 50000,
  currency: "RUB",
  return_url: "https://shop.example/thanks",
});
payment = client.payments.create(
    amount=50000,
    currency="RUB",
    return_url="https://shop.example/thanks",
)

Получить платёж

GET/v1/payments/{id}

curl https://api.kvant.example/v1/payments/pay_2Hq8sK1mXz \
  -H "Authorization: Bearer $KVANT_SECRET_KEY"
const payment = await kvant.payments.retrieve("pay_2Hq8sK1mXz");
payment = client.payments.retrieve("pay_2Hq8sK1mXz")

Список платежей

GET/v1/payments

ПараметрТипОписание
limitintegerОт 1 до 100, по умолчанию 10.
starting_afterstringID платежа, после которого начать — для пагинации.
statusstringФильтр по статусу.

Вернуть деньги

POST/v1/payments/{id}/refunds

Без amount возвращается вся сумма. Частичных возвратов может быть несколько, пока их сумма не превысит платёж.

curl https://api.kvant.example/v1/payments/pay_2Hq8sK1mXz/refunds \
  -H "Authorization: Bearer $KVANT_SECRET_KEY" \
  -d amount=15000
await kvant.payments.refund("pay_2Hq8sK1mXz", { amount: 15000 });
client.payments.refund("pay_2Hq8sK1mXz", amount=15000)
