Справочник API

Ошибки и лимиты

API использует HTTP-коды: 2xx — успех, 4xx — ошибка в запросе, 5xx — сбой на нашей стороне.

Формат ошибки

{
  "error": {
    "type": "invalid_request",
    "code": "amount_too_small",
    "message": "Минимальная сумма платежа — 1 ₽ (100 копеек).",
    "param": "amount"
  }
}

Коды ответов

КодЗначениеЧто делать
400Неверные параметрыСмотрите поле param
401Нет или неверный ключПроверьте заголовок Authorization
404Объект не найденПроверьте ID и среду (test/live)
409Конфликт идемпотентностиТот же ключ с другими параметрами
429Превышен лимит запросовПовторите после Retry-After
500Ошибка сервераПовторите с тем же Idempotency-Key

Лимиты запросов

100 запросов в секунду на ключ в боевой среде и 25 — в тестовой. Текущее состояние лимита возвращается в заголовках RateLimit-Remaining и RateLimit-Reset.

Повтор с задержкой

async function withRetry(fn, attempts = 4) {
  for (let i = 0; ; i++) {
    try { return await fn(); }
    catch (err) {
      const retryable = err.status === 429 || err.status >= 500;
      if (!retryable || i === attempts - 1) throw err;
      await new Promise((r) => setTimeout(r, 2 ** i * 500));
    }
  }
}
