# Гараж 24 — сайт автосервиса

**Сайт услуг с калькулятором (одностраничный)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-auto-service/index.html)**

![Десктоп](screenshots/desktop.png)

Брутальный тёмный сайт автосервиса: калькулятор стоимости работ с коэффициентом класса автомобиля и оценкой времени, сетка услуг, проверка статуса ремонта по номеру заказ-наряда с прогрессом по этапам и форма записи с валидацией.

## Возможности

- Калькулятор: класс авто × выбранные работы, время ремонта и подсказка «подождать / оставить на день»
- Расчёт подставляется в форму записи
- Статус ремонта по номеру заказа (демо-номера G24-1048, G24-2210, G24-0777) с этапами
- Запись: проверка марки, года выпуска, даты, имени и телефона
- Иллюстрация автомобиля и элементы интерфейса на SVG/CSS

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: калькулятор, статус заказа, запись
- Шрифты: Russo One, Roboto Condensed — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-auto-service/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
