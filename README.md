# Квант API — документация

**Сайт документации (мультистраничный)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-docs-site/index.html)**

![Десктоп](screenshots/desktop.png)

Документация вымышленного платёжного API: пять страниц с общей навигацией, поиском по Ctrl+K, вкладками примеров кода (cURL / Node.js / Python) с подсветкой и копированием, оглавлением со scrollspy и тёмной темой.

## Возможности

- 5 страниц: обзор, аутентификация, платежи, вебхуки, ошибки и лимиты
- Поиск в модальном окне: Ctrl+K или /, стрелки, Enter, подсветка совпадений, индекс разделов
- Вкладки языков синхронизируются во всех примерах и запоминаются между страницами
- Лёгкая подсветка синтаксиса без библиотек и кнопка «Копировать»
- Оглавление «На этой странице» с подсветкой текущего раздела и якорные ссылки у заголовков
- Таблицы параметров, методы эндпоинтов, врезки-предупреждения, навигация «Назад / Далее»
- Светлая и тёмная тема, мобильное меню

## Страницы

- `index.html` — Обзор
- `auth.html` — Аутентификация
- `payments.html` — Платежи
- `webhooks.html` — Вебхуки
- `errors.html` — Ошибки и лимиты

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: docs.js, search-index.js
- Шрифты: Sofia Sans, JetBrains Mono — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-docs-site/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
