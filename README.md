# Вера Лис — портфолио иллюстратора

**Портфолио (творческий одностраничный сайт)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-illustrator-portfolio/index.html)**

![Десктоп](screenshots/desktop.png)

Тёмное минималистичное портфолио художника: полноэкранный первый экран, галерея-мозаика с фильтром по сериям, полноэкранный просмотр работ, блок о себе, прайс на принты и форма заказа. Все 14 работ — процедурно сгенерированные SVG-пейзажи.

## Возможности

- Мозаичная галерея (CSS columns) с фильтром по сериям
- Лайтбокс на <dialog>: стрелки ←/→, Esc, возврат фокуса к работе
- Кнопка «Заказать принт» из лайтбокса подставляет работу в форму
- Медленная анимация фона первого экрана (выключается при prefers-reduced-motion)
- Форма заказа с зависимыми полями и проверкой

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: галерея, фильтр, лайтбокс, форма
- Шрифты: Cormorant Garamond, Jost — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-illustrator-portfolio/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
