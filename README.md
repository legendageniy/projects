# Горизонт — сайт турагентства

**Каталог туров с бронированием (многостраничный)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-travel-agency/index.html)**

![Десктоп](screenshots/desktop.png)

Сайт турагентства авторских туров: главная с быстрым подбором по региону и месяцу, каталог с фильтрами и сортировкой, страница тура с программой по дням, датами выезда, сезонными ценами и расчётом стоимости на группу. Иллюстрации к каждому туру генерируются в SVG.

## Возможности

- Быстрый подбор тура с главной (параметры передаются в каталог через URL)
- Фильтры: регион, месяц, длительность, бюджет-слайдер, сортировка
- Даты выезда вычисляются по сезону тура, с сезонной наценкой и остатком мест
- Калькулятор: взрослые, дети со скидкой 30%, одноместное размещение
- Программа по дням в виде таймлайна с раскрывающимися днями
- Генеративные SVG-пейзажи: горы, вулкан, озеро, лес, город, северное сияние, море

## Страницы

- `index.html` — главная
- `tours.html` — каталог
- `tour.html?id=kamchatka` — страница тура

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: подбор, фильтры, даты выезда, расчёт стоимости
- Шрифты: PT Serif, PT Sans — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-travel-agency/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
