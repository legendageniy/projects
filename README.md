# Пятая линия — городское издание

**Новостной портал / медиа (мультистраничный)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-news-portal/index.html)**

![Десктоп](screenshots/desktop.png)

Сайт городского издания в газетной эстетике: главная с главным материалом, бегущей строкой, рубриками и «Самым читаемым», лента рубрики с сортировкой и подгрузкой, страница статьи с прогрессом чтения и настройкой размера текста.

## Возможности

- Главная: главный материал, последние новости, бегущая строка (пауза при наведении), блоки рубрик, топ по просмотрам, форма рассылки
- Рубрика (category.html?c=…): сортировка «новые / популярные», кнопка «Показать ещё» с переводом фокуса
- Статья (article.html?id=…): индикатор прогресса чтения, A−/A+ с запоминанием, копирование ссылки, буквица, цитаты, «Следующий материал» и «Читайте также», состояние «не найдено»
- Генеративные SVG-обложки: свой мотив для каждой рубрики
- Время публикации относительное: «3 ч назад», «вчера, 14:20»

## Страницы

- `index.html` — Главная
- `category.html` — Рубрика
- `article.html` — Статья

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: news.js, portal.js
- Шрифты: Playfair Display, Source Serif 4, Inter Tight — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-news-portal/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
