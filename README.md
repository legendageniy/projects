# Модуль — конфигуратор диванов

**Интернет-магазин с конфигуратором товара** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-furniture-configurator/index.html)**

![Десктоп](screenshots/desktop.png)

Магазин мебели под заказ: конфигуратор дивана с живым SVG-превью, планом сверху и проверкой «встанет ли у стены», расчёт цены и срока изготовления, ссылка на конфигурацию и корзина с сохранением.

## Возможности

- Форма (прямой / угловой / П-образный), число мест, 6 тканей с фактурой (букле, велюр, рогожка), ножки, подушки
- SVG-превью дивана и план сверху перерисовываются при каждом изменении
- Проверка размера: длина стены → «встанет / впритык / не встанет» с цветом и текстом
- Цена и дата изготовления зависят от модели, ткани и опций
- Конфигурация сохраняется в адресе страницы — ссылкой можно поделиться
- Корзина в боковой панели с миниатюрами, удалением, условием бесплатной сборки и сохранением в localStorage
- Каталог тканей с кнопкой «Примерить на диван»

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: script.js
- Шрифты: Jost — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-furniture-configurator/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
