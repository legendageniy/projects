# Пульс CRM — панель продаж

**Веб-приложение / админ-панель** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-admin-dashboard/index.html)**

![Десктоп](screenshots/desktop.png)

Интерфейс CRM без сборки: дашборд с KPI, интерактивными SVG-графиками и планом менеджеров, таблица сделок с поиском, фильтрами, сортировкой, пагинацией и экспортом CSV, канбан-воронка с перетаскиванием и тёмная тема.

## Возможности

- Хеш-роутинг между разделами «Обзор», «Сделки», «Воронка»
- KPI с дельтой к прошлому периоду и спарклайнами, переключатель 7/30/90 дней
- Линейный график выручки с перекрестием, подсказкой, управлением стрелками и табличным представлением
- Воронка (ordinal-шкала), источники сделок (горизонтальные бары с подсказками), выполнение плана со статусами иконка+текст
- Таблица сделок: глобальный поиск (клавиша /), фильтры, сортировка с aria-sort, пагинация, экспорт CSV
- Карточка сделки в боковой панели с ловушкой фокуса и сменой этапа
- Канбан: drag-and-drop и кнопки ← → для клавиатуры
- Светлая и тёмная тема (системная + переключатель с запоминанием); палитра графиков проверена на дальтонизм

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: data.js, app.js
- Шрифты: Inter, Fira Code — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-admin-dashboard/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
