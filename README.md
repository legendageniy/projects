# Байт — технический блог

**Блог (многостраничный)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-tech-blog/index.html)**

![Десктоп](screenshots/desktop.png)

Блог о веб-разработке: лента статей с главным материалом, поиском и фильтром по тегам, страница статьи с оглавлением, подсветкой кода и кнопками копирования, страница «О блоге». Светлая и тёмная тема.

## Возможности

- Поиск по статьям и фильтр по тегам (тег сохраняется в URL)
- Страница статьи: оглавление с подсветкой текущего раздела, индикатор прочтения
- Подсветка синтаксиса и кнопка «Копировать» у блоков кода
- Тёмная тема: по системной настройке или переключателем, выбор запоминается
- Навигация «предыдущая / следующая статья»
- Форма подписки на рассылку

## Страницы

- `index.html` — лента статей
- `post.html?slug=postgres-indexes` — статья
- `about.html` — о блоге

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: рендер статей из данных, поиск, теги, оглавление, подсветка кода, тема
- Шрифты: Inter, Source Serif 4, JetBrains Mono — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-tech-blog/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
