# Совёнок — детский развивающий центр

**Лендинг детского центра** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-kids-center/index.html)**

![Десктоп](screenshots/desktop.png)

Яркий сайт детского центра: фильтр занятий по возрасту, недельное расписание с подсветкой групп, абонементы с переключателем числа занятий, игра «Найди пару» и запись на пробное занятие в модальном окне.

## Возможности

- Фильтр по возрасту одновременно меняет карточки программ и подсветку в расписании
- Расписание-таблица с горизонтальной прокруткой на мобильных
- Абонементы: 4/8/12 занятий, пересчёт цены за занятие
- Игра «Найди пару» с 3D-переворотом карточек, счётчиком ходов и доступными подписями
- Запись в <dialog>: возраст → подходящие занятия → реальные слоты из расписания
- Все иллюстрации — SVG (сова-маскот, зверята)

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: script.js
- Шрифты: Montserrat Alternates, Amatic SC — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-kids-center/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
