# Мера — сайт медицинского центра с онлайн-записью

**Сайт клиники с записью к врачу** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-medical-clinic/index.html)**

![Десктоп](screenshots/desktop.png)

Сайт многопрофильного медицинского центра: поиск по врачам и услугам, каталог врачей с фильтром по специальности, пошаговая онлайн-запись (врач → день → свободное время → данные пациента), прайс с поиском, чекапы и блок обязательных сведений с местами для реквизитов.

## Возможности

- Единый поиск: находит врача или переводит к нужной услуге в прайсе
- Фильтр врачей по специальности и быстрые ссылки
- Запись: 7 ближайших дней, свободные слоты с учётом графика выходного дня
- Проверка ФИО, телефона, даты рождения и согласия на обработку данных о здоровье
- Прайс-лист: группы-аккордеоны и мгновенный поиск
- Блок «Документы и сведения» с плейсхолдерами для лицензии

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: поиск, фильтры, запись к врачу, прайс
- Шрифты: Nunito — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-medical-clinic/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
