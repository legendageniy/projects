# Поток — лендинг SaaS-сервиса

**Лендинг (одностраничный сайт) SaaS-продукта** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-saas-landing/index.html)**

![Десктоп](screenshots/desktop.png)

Продающий лендинг таск-менеджера для команд: интерфейс продукта нарисован на HTML/CSS прямо в первом экране, блоки возможностей, шаги подключения, интеграции, тарифы с переключением периода оплаты, FAQ и форма регистрации.

## Возможности

- Макет приложения (канбан-доска) на чистом HTML/CSS
- Переключатель тарифов «месяц / год» с пересчётом цен
- Форма регистрации с валидацией email
- Аккордеон FAQ на details/summary
- Плавное появление блоков при прокрутке (с учётом prefers-reduced-motion)
- Мобильное меню-бургер

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: меню, тарифы, валидация формы, анимации появления
- Шрифты: Manrope — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-saas-landing/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
