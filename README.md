# Андрей Соколов — онлайн-резюме разработчика

**Резюме / CV (одностраничный сайт)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-cv-resume/index.html)**

![Десктоп](screenshots/desktop.png)

Аккуратное онлайн-резюме в виде листа: опыт с результатами в цифрах, навыки с уровнем, проекты, образование и языки. Переключение русской и английской версии, отдельная вёрстка для печати и сохранения в PDF формата A4.

## Возможности

- Переключение RU / EN без перезагрузки, выбор запоминается
- Кнопка «Скачать PDF» и стили печати: A4, две колонки, без панели инструментов
- Копирование email в буфер обмена с уведомлением
- Уровни навыков на семантическом <meter>
- Адаптивная вёрстка листа для телефона

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: переключение языка, копирование, печать
- Шрифты: Raleway, IBM Plex Mono — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-cv-resume/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
