# Код+ — сайт онлайн-школы программирования

**Лендинг онлайн-школы (EdTech)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-online-school/index.html)**

![Десктоп](screenshots/desktop.png)

Продающая страница онлайн-школы: редактор кода с эффектом набора в первом экране, каталог курсов с фильтрами, интерактивный тест подбора курса, программа обучения, тарифы с переключением «сразу / в рассрочку», FAQ и форма записи на бесплатный урок.

## Возможности

- Анимация набора кода с подсветкой синтаксиса и выводом результата
- Каталог курсов с двумя фильтрами (направление и уровень)
- Тест из трёх вопросов с прогрессом и персональной рекомендацией
- Аккордеон программы и FAQ на details/summary
- Переключатель цен: полная оплата / ежемесячный платёж
- Форма записи с проверкой телефона или @telegram

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: эффект набора, фильтры, тест, тарифы, форма
- Шрифты: Unbounded, Golos Text, JetBrains Mono — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-online-school/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
