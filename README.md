# Меридиан — сайт консалтинговой компании

**Корпоративный сайт (многостраничный)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-consulting-corporate/index.html)**

![Десктоп](screenshots/desktop.png)

Строгий корпоративный сайт B2B-компании: главная с графиком результатов, услуги с боковой навигацией, страница о компании с командой и историей, контакты со схемой проезда и формой заявки.

## Возможности

- SVG-график результатов в первом экране
- Анимированные счётчики цифр при прокрутке
- Фильтр кейсов по отраслям (вкладки)
- Страница услуг с подсветкой текущего раздела (scroll-spy)
- Форма заявки с валидацией и согласием на обработку данных
- Схема проезда на SVG, без внешних карт

## Страницы

- `index.html` — главная
- `services.html` — услуги
- `about.html` — о компании
- `contacts.html` — контакты и форма

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: меню, счётчики, фильтр кейсов, scroll-spy, валидация формы
- Шрифты: IBM Plex Sans, Literata — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-consulting-corporate/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
