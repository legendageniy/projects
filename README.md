## Как посмотреть

- **Онлайн:** ссылка «открыть» в таблице (сервис raw.githack.com показывает HTML прямо из ветки).
- **Локально:** откройте ветку → **Code → Download ZIP** → распакуйте и откройте `index.html` в браузере.
- **Через git:** `git clone -b site-<название> --single-branch https://github.com/legendageniy/projects.git`

## Общее для всех сайтов

- Семантическая вёрстка, работа с клавиатуры, подписи у полей, видимый фокус, `prefers-reduced-motion`.
- Адаптивность от 320 px; каждый сайт проверен в Chromium на 1440 px и 390 px: без горизонтальной прокрутки, ошибок в консоли, битых ссылок и дублирующихся `id`.
- Шрифты подключены локально (лицензия SIL OFL), иллюстрации — SVG и CSS, внешних запросов нет.
- Все компании, люди, цены и контакты вымышлены — это демо-шаблоны.
