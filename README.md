# Корочка — сайт пекарни с предзаказом

**Небольшой интернет-магазин (предзаказ и самовывоз)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-bakery-shop/index.html)**

![Десктоп](screenshots/desktop.png)

Уютный сайт пекарни: каталог хлеба, выпечки и десертов с SVG-иллюстрациями, фильтры по категориям и аллергенам, корзина в выезжающей панели и оформление предзаказа с выбором дня и часа самовывоза по правилам пекарни.

## Возможности

- Фильтр «без глютена / орехов / молока» вместе с категориями
- Корзина-панель: управление фокусом, закрытие по Esc и клику на фон, inert для фона, данные в localStorage
- Правила самовывоза: заказ на завтра только до 20:00, понедельник — выходной, в выходные с 9:00
- Изменение количества, итог и подтверждение заказа
- Иллюстрации выпечки нарисованы в SVG

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: каталог, фильтры, корзина, правила самовывоза
- Шрифты: Pacifico, Nunito Sans — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-bakery-shop/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
