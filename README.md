# Прана — сайт студии йоги

**Сайт студии (одностраничный, запись на занятия)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-yoga-studio/index.html)**

![Десктоп](screenshots/desktop.png)

Спокойный тёплый сайт студии йоги: расписание на неделю с фильтрами и записью в модальном окне, интерактивная практика «квадратного дыхания», подбор самого выгодного абонемента по частоте занятий, преподаватели и контакты.

## Возможности

- Сетка расписания на 7 дней: фильтр по направлению и уровню, подсветка сегодняшнего дня
- Запись на занятие в <dialog> с проверкой имени и телефона
- Дыхательная практика 4×4 с анимацией круга, счётчиком кругов и остановкой
- Калькулятор абонемента: учитывает число занятий и срок действия пакета
- Иллюстрации на SVG, мягкие формы и типографика Tenor Sans + Lora

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: расписание, запись, дыхательная практика, подбор абонемента
- Шрифты: Tenor Sans, Lora — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-yoga-studio/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
