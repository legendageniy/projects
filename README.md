# Чисто и точка — клининговая компания

**Лендинг услуг с калькулятором** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-cleaning-company/index.html)**

![Десктоп](screenshots/desktop.png)

Сайт клининговой компании: калькулятор стоимости уборки с опциями и скидкой за регулярность, чек-листы по помещениям, слайдер «до/после» и онлайн-запись на свободное время.

## Возможности

- Калькулятор: вид уборки, площадь, санузлы, допуслуги, частота; расчёт числа клинеров и времени
- Чек-лист работ по помещениям во вкладках (стрелки на клавиатуре)
- Слайдер «до и после» на range-input и clip-path, обе картинки — SVG
- Выбор дня и времени с занятыми слотами, параметры уборки подставляются в запись
- FAQ на details/summary, валидация формы

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: script.js
- Шрифты: Onest — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-cleaning-company/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
