# Frontend Days 2027 — сайт IT-конференции

**Сайт мероприятия (лендинг конференции)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-conference-event/index.html)**

![Десктоп](screenshots/desktop.png)

Сайт конференции в стиле необрутализма: обратный отсчёт до начала, бегущая строка тем, программа по дням и трекам с личным расписанием, карточки спикеров с модальным окном, билеты с ранней ценой, промокодом и групповой скидкой, схема площадки.

## Возможности

- Живой обратный отсчёт до начала
- Программа: переключение дней, фильтр по треку, «Моё расписание» (звёздочки сохраняются в localStorage)
- Спикеры: модальное окно с биографией и списком докладов
- Билеты: ранняя цена по дате, промокод FRONT10, скидка от 5 билетов
- Схема залов площадки на CSS Grid

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: таймер, расписание, избранное, модальные окна, расчёт билетов
- Шрифты: Rubik Mono One, Rubik — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-conference-event/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
