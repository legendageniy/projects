# Линия — сайт архитектурного бюро

**Портфолио студии (многостраничный, минимализм)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-architecture-bureau/index.html)**

![Десктоп](screenshots/desktop.png)

Строгий минималистичный сайт архитектурного бюро: сетка проектов разной ширины с фильтром, страница проекта со слайдером сравнения «эскиз ↔ визуализация», характеристиками и навигацией между проектами, страница бюро с принципами, этапами работы и формой обращения. Фасады генерируются кодом в двух стилях: линейный чертёж и цветная визуализация.

## Возможности

- Генератор фасадов на SVG: этажность, пролёты, тип кровли (плоская, двускатная, пилообразная, сводчатая)
- Слайдер сравнения: перетаскивание мышью/пальцем и доступный input range для клавиатуры
- Сетка проектов с «широкими» карточками, которая не оставляет пустых ячеек
- Фильтр проектов по типу
- Навигация «предыдущий / следующий проект»

## Страницы

- `index.html` — проекты
- `project.html?id=library` — страница проекта
- `studio.html` — о бюро и контакты

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: генерация фасадов, фильтр, слайдер сравнения
- Шрифты: Fira Sans, Spectral — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-architecture-bureau/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
