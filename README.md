# Сосны — сайт загородного отеля с бронированием

**Сайт отеля с онлайн-бронированием (многостраничный)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-hotel-booking/index.html)**

![Десктоп](screenshots/desktop.png)

Сайт эко-отеля: иллюстрированный первый экран с поиском по датам, подборка номеров, досуг и ресторан; страница номеров с фильтром по вместимости и ценой за выбранные даты; страница бронирования с живым расчётом стоимости.

## Возможности

- Поиск по датам заезда/выезда с подсчётом ночей
- Каталог номеров: фильтр по числу гостей, сортировка, итоговая цена за весь период
- Расчёт стоимости: будние и выходные тарифы, завтраки на каждого гостя, трансфер
- Форма бронирования с проверкой дат и контактов
- Интерьеры номеров и пейзаж — SVG-иллюстрации

## Страницы

- `index.html` — главная с поиском
- `rooms.html` — номера
- `booking.html?room=chalet` — бронирование

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: поиск, фильтр номеров, калькулятор стоимости, валидация
- Шрифты: Playfair Display, Mulish — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-hotel-booking/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
