# Шаги — лендинг мобильного приложения

**Промо-лендинг мобильного приложения** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-mobile-app-promo/index.html)**

![Десктоп](screenshots/desktop.png)

Лёгкий яркий лендинг приложения-шагомера: два телефона на чистом CSS в первом экране, интерактивная демонстрация — ползунки шагов и цели меняют кольцо прогресса, статистику и недельный график внутри телефона; вкладки возможностей переключают экран, тарифы и FAQ.

## Возможности

- Макеты телефонов и интерфейс приложения целиком на HTML/CSS (conic-gradient для кольца прогресса)
- Живая демонстрация: шаги и цель пересчитывают км, ккал, минуты, график недели и подсказку
- Вкладки возможностей со сменой экрана телефона, управление стрелками
- Кнопки магазинов приложений без логотипов-товарных знаков
- Тарифы и FAQ

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: интерактивная демонстрация, вкладки
- Шрифты: Comfortaa, Nunito — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-mobile-app-promo/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
