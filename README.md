# Разговоры на кухне — сайт подкаста

**Сайт подкаста с аудиоплеером** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-podcast/index.html)**

![Десктоп](screenshots/desktop.png)

Тёплый сайт подкаста: обложка, последний выпуск, список выпусков с поиском и фильтром по темам, ведущие и подписка. Встроенный настоящий аудиоплеер — короткая демо-мелодия синтезируется в браузере и кодируется в WAV, поэтому работают все функции <audio>.

## Возможности

- Аудиоплеер на HTML5 <audio>: пауза, перемотка, ±15 секунд, скорость 1× / 1,5× / 2×
- Мини-плеер, закреплённый внизу экрана, синхронизирован с кнопками выпусков
- Звук генерируется кодом (аккорды и переборы), кодируется в WAV без внешних файлов
- Поиск по выпускам и фильтр по темам
- Подписка на рассылку с проверкой email

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: синтез аудио, плеер, поиск и фильтры
- Шрифты: Neucha, Open Sans — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-podcast/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
