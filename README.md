# Шум — сайт креативного агентства

**Сайт агентства (одностраничный, креативный)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-marketing-agency/index.html)**

![Десктоп](screenshots/desktop.png)

Дерзкий сайт маркетингового агентства: гигантская типографика, мягкое пятно за курсором, бегущая строка, кейсы с генеративными обложками и фильтром, раскрывающийся список услуг с ценами, команда и пошаговый бриф с итоговой сводкой.

## Возможности

- Пятно-градиент, плавно следующее за курсором (только мышь, выключается при reduced motion)
- Генеративные SVG-обложки кейсов и фильтр по направлениям
- Аккордеон услуг с ценами и сроками
- Бриф в 4 шага: услуги, бюджет-слайдер, сроки, контакты — с проверкой каждого шага
- Необычные «арочные» карточки команды на CSS

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: эффект курсора, фильтр кейсов, аккордеон, пошаговый бриф
- Шрифты: Dela Gothic One, Montserrat — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-marketing-agency/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
