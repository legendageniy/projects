# Улей — сайт коворкинга со схемой этажа

**Сайт с интерактивной схемой и бронированием** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-coworking/index.html)**

![Десктоп](screenshots/desktop.png)

Сайт коворкинга: интерактивный SVG-план этажа (open space, тихая зона, переговорные), занятость меняется по дате и времени, места выбираются мышью или с клавиатуры; тарифы, почасовое бронирование переговорных с проверкой непрерывного интервала и список удобств.

## Возможности

- SVG-план этажа: 44 места и 3 переговорные, состояния «свободно / занято / выбрано»
- Выбор места с клавиатуры (Tab + Enter), ARIA-описания для скринридеров
- Занятость зависит от даты и интервала и согласована с почасовой сеткой переговорных
- Бронирование переговорной: выбор нескольких часов подряд, расчёт стоимости
- Сотовый паттерн и шестиугольники на чистом CSS/SVG

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: интерактивный план, бронирование мест и переговорных
- Шрифты: Exo 2, Sofia Sans — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-coworking/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
