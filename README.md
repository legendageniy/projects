# Анна и Максим — свадебный сайт-приглашение

**Сайт-приглашение на событие (одностраничный)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-wedding-invite/index.html)**

![Десктоп](screenshots/desktop.png)

Нежный свадебный сайт: имена каллиграфическим шрифтом, обратный отсчёт, программа дня на таймлайне, схема проезда, палитра дресс-кода и анкета гостя с условными полями. Кнопка «Добавить в календарь» создаёт настоящий .ics-файл с напоминанием за день.

## Возможности

- Обратный отсчёт до церемонии
- Генерация календарного файла .ics (RFC 5545) с напоминанием — открывается в Google, Apple и Outlook
- Анкета RSVP: дополнительные вопросы появляются только при ответе «приду»
- Ответ запоминается на устройстве, его можно изменить
- Палитра дресс-кода, ботанические SVG-веточки, схема проезда

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: таймер, календарный файл, анкета гостя
- Шрифты: Marck Script, Prata, Philosopher — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-wedding-invite/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
