# Северный ветер — сайт музыкальной группы

**Сайт музыканта / группы** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-music-band/index.html)**

![Десктоп](screenshots/desktop.png)

Атмосферный тёмный сайт группы: анимированное «северное сияние» на canvas в первом экране, концертный тур с автоматическим разделением на прошедшие и будущие даты, фильтром по городам и статусами билетов, дискография с генеративными обложками и прослушиванием фрагментов, синтезированных Web Audio API, с живым визуализатором спектра.

## Возможности

- Северное сияние на canvas (останавливается при prefers-reduced-motion)
- Тур: прошедшие концерты определяются по текущей дате, фильтр по городу, «Sold out» и «Последние билеты»
- Фрагменты песен синтезируются Web Audio (пэд + арпеджио), один трек за раз
- Визуализатор спектра через AnalyserNode на canvas
- Генеративные обложки альбомов, подписка на новости

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: canvas-анимация, тур, Web Audio и визуализатор
- Шрифты: Oswald, Roboto Slab — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-music-band/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
