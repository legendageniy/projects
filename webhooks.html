Справочник API

Вебхуки

Вебхуки сообщают вашему серверу о событиях: платёж прошёл, возврат выполнен, платёж отменён. Не опрашивайте API в цикле — подпишитесь на события.

События

ПараметрТипОписание
payment.succeededeventДеньги списаны, заказ можно отгружать.
payment.canceledeventПокупатель отказался или истекло время.
refund.succeededeventВозврат зачислен покупателю.

Тело запроса

{
  "id": "evt_9Lm2Qa7",
  "type": "payment.succeeded",
  "created_at": "2026-10-20T09:41:15Z",
  "data": { "object": { "id": "pay_2Hq8sK1mXz", "amount": 50000, "status": "succeeded" } }
}

Проверка подписи

Каждый запрос содержит заголовок Kvant-Signature — HMAC-SHA256 от тела запроса с вашим секретом вебхука. Проверяйте подпись до любой обработки.

import crypto from "node:crypto";

export function verify(rawBody, header, secret) {
  const expected = crypto.createHmac("sha256", secret).update(rawBody).digest("hex");
  const a = Buffer.from(expected), b = Buffer.from(header ?? "");
  return a.length === b.length && crypto.timingSafeEqual(a, b);
}
import hmac, hashlib

def verify(raw_body: bytes, header: str, secret: str) -> bool:
    expected = hmac.new(secret.encode(), raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, header or "")

Сырые данные. Считайте подпись по исходным байтам тела, до парсинга JSON — иначе пробелы и порядок ключей изменят хеш.

Повторы

Ответьте кодом 2xx в течение 10 секунд. Иначе запрос повторится через 1, 5, 30 минут, затем каждые 2 часа в течение суток. События могут прийти повторно или не по порядку — обрабатывайте их идемпотентно по id.
