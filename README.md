# Сулико — сайт грузинского ресторана

**Одностраничный сайт ресторана** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-restaurant-onepage/index.html)**

![Десктоп](screenshots/desktop.png)

Тёплый одностраничный сайт ресторана: иллюстрированный первый экран, меню с вкладками и фильтром «без мяса», блок о ресторане, онлайн-бронирование с подбором свободного времени и контакты со схемой проезда.

## Возможности

- Меню по разделам: доступные вкладки (стрелки ←/→), фильтр вегетарианских блюд
- Статус «Открыто до … / Закрыто» в шапке по часам работы
- Бронирование: даты на 60 дней вперёд, время только из часов работы (с учётом текущего времени), выбор зала, число гостей
- Валидация формы и подтверждение с деталями брони
- Иллюстрации и карта на SVG

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: меню, фильтр, часы работы, бронирование
- Шрифты: Yeseva One, Nunito Sans — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-restaurant-onepage/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
