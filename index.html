Введение

Обзор

Квант API позволяет принимать платежи, оформлять возвраты и получать уведомления о статусах. Это REST API: ресурсы по понятным URL, ответы в JSON, стандартные HTTP-коды.

Базовый адрес

Все запросы отправляются по HTTPS. Тестовая и боевая среды различаются только ключом — адрес один.

https://api.kvant.example/v1

Быстрый старт

Создайте тестовый платёж на 500 ₽. Ключ sk_test_… можно скопировать в личном кабинете в разделе «Разработчикам».

curl https://api.kvant.example/v1/payments \
  -H "Authorization: Bearer sk_test_ВАШ_КЛЮЧ" \
  -H "Idempotency-Key: 5f1c2a8e-order-1042" \
  -d amount=50000 \
  -d currency=RUB \
  -d description="Заказ №1042"
import Kvant from "@kvant/node";

const kvant = new Kvant(process.env.KVANT_SECRET_KEY);

const payment = await kvant.payments.create({
  amount: 50000, // в копейках
  currency: "RUB",
  description: "Заказ №1042",
}, { idempotencyKey: "5f1c2a8e-order-1042" });

console.log(payment.confirmation_url);
import os
import kvant

client = kvant.Client(os.environ["KVANT_SECRET_KEY"])

payment = client.payments.create(
    amount=50000,  # в копейках
    currency="RUB",
    description="Заказ №1042",
    idempotency_key="5f1c2a8e-order-1042",
)
print(payment.confirmation_url)

В ответе придёт объект платежа со статусом pending и ссылкой confirmation_url, на которую нужно перенаправить покупателя.

Суммы и валюты

Суммы передаются целым числом в минимальных единицах валюты: для рублей — в копейках. 500 ₽ — это 50000.

Совет. Храните суммы в базе тоже в копейках — так не будет ошибок округления при сложении.
