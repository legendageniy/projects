# Букетная — доставка цветов

**Интернет-магазин / конструктор товара** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-flower-delivery/index.html)**

![Десктоп](screenshots/desktop.png)

Магазин цветов с конструктором букета: выбор цветов, оттенков, зелени и упаковки с живым SVG-превью и пересчётом цены, готовые букеты и оформление доставки по интервалам.

## Возможности

- Конструктор букета: количество и оттенок каждого цветка, зелень, упаковка
- SVG-превью букета перерисовывается при каждом изменении
- Готовые букеты рисуются тем же генератором и подставляются в конструктор
- Интервалы доставки зависят от даты и текущего времени
- Расчёт итога: бесплатная доставка от 5 000 ₽
- Счётчик символов открытки, валидация формы

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: script.js
- Шрифты: Noto Serif, Inter Tight — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-flower-delivery/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
