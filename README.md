# Тёплый дом — сайт благотворительного фонда

**Сайт некоммерческой организации (пожертвования)** — демо-шаблон сайта из портфолио.

**[Открыть онлайн →](https://raw.githack.com/legendageniy/projects/site-charity-fund/index.html)**

![Десктоп](screenshots/desktop.png)

Сайт благотворительного фонда: форма пожертвования с выбором суммы и периодичности и подсказкой, на что пойдут деньги; открытые сборы с прогрессом; прозрачный отчёт о расходах по месяцам с кольцевой диаграммой и таблицей; анкета волонтёра.

## Возможности

- Пожертвование: разовое или ежемесячное, суммы-кнопки или своя сумма, текст кнопки меняется вместе с суммой
- Подсказка «что сделает ваша сумма» для каждого порога
- Сборы с доступными прогресс-барами (role=progressbar)
- Отчёт: кольцевая диаграмма на conic-gradient и таблица расходов, выбор месяца
- Анкета волонтёра с выбором вариантов помощи

## Технологии

- HTML5, семантическая разметка, доступность (клавиатура, ARIA, контраст)
- CSS3: Grid, Flexbox, custom properties, адаптивная вёрстка от 320 px
- JavaScript без фреймворков и сборки: форма пожертвования, отчёты, анкета
- Шрифты: Alegreya, Commissioner, Caveat — локально, лицензия SIL OFL (`fonts/`)
- Без внешних запросов: иллюстрации — SVG и CSS

## Как запустить

- Онлайн: https://raw.githack.com/legendageniy/projects/site-charity-fund/index.html
- Локально: скачайте ветку (**Code → Download ZIP**) и откройте `index.html` в браузере — сервер и установка не нужны.
